# گزارش فعالیت‌های انجام‌شده و مشکلات فنی پروژه سیستم کنترل هوشمند دسترسی به درب

موضوع: گزارش روند راه‌اندازی محیط توسعه و شبیه‌سازی میکروکنترلر ESP32\
پروژه: سیستم کنترل هوشمند دسترسی به درب

## ۱. اقدامات انجام‌شده

در راستای پیاده‌سازی بخش سخت‌افزاری پروژه، تلاش شد محیط توسعه ESP32 در Visual Studio Code راه‌اندازی شود.

اقدامات انجام‌شده به ترتیب عبارت‌اند از:

1. ساخت ساختار اولیه پوشه‌های پروژه در GitHub و آماده‌سازی فایل `main.cpp` در مسیر `esp32/src/`.
2. نصب افزونه PlatformIO در VS Code و تلاش برای استفاده از آن به‌عنوان محیط توسعه ESP32؛ اما به دلیل مشکلات دسترسی و محدودیت‌های منطقه‌ای، امکان استفاده از آن فراهم نشد.
3. بررسی امکان استفاده از Arduino IDE؛ اما نصب و راه‌اندازی آن با مشکل مواجه شد.
4. انتخاب Arduino CLI به‌عنوان جایگزین Arduino IDE و نصب نسخه 1.5.1 آن.
5. بررسی اجرای Arduino CLI از طریق ترمینال داخلی VS Code. مشخص شد که برنامه نصب شده است، اما به دلیل تنظیم نبودن PATH، دستور مستقیم `arduino-cli` شناسایی نمی‌شود. این مشکل با اجرای برنامه از طریق مسیر کامل فایل اجرایی برطرف شد.
6. تلاش برای به‌روزرسانی فهرست پکیج‌ها و نصب هسته ESP32 از طریق Arduino CLI.

## ۲. مشکلات و موانع فنی

در جریان راه‌اندازی Arduino CLI، مشکلات زیر مشاهده شد:

- سرور دانلود رسمی Arduino هنگام دریافت فایل‌های موردنیاز، خطای `403 Forbidden` برگرداند.
- فایل‌های مربوط به Package Index و Library Index به‌درستی دریافت نشدند.
- به دلیل دریافت نشدن فایل‌های موردنیاز، Arduino CLI نتوانست پلتفرم سخت‌افزاری را بارگذاری کند.
- در نتیجه، دستور `core list` هیچ پلتفرم نصب‌شده‌ای را نمایش نداد.
- همچنین مؤلفه‌های داخلی مربوط به شناسایی پورت سریال و دستگاه‌ها به‌درستی راه‌اندازی نشدند.

با این حال، بررسی آدرس مخزن رسمی Espressif نشان داد که فایل مربوط به پکیج ESP32 از طریق مرورگر قابل دسترسی است و پاسخ HTTP 200 دریافت می‌شود. بنابراین، مشکل دسترسی به سرور Arduino با مشکل دسترسی به مخزن Espressif یکسان نیست.

## ۳. بررسی اجرای برنامه در VS Code

کد اولیه کنترل LEDها در فایل `main.cpp` قرار داده شد.

این برنامه شامل قابلیت‌های زیر است:

- تعریف دو خروجی برای LED سبز و قرمز.
- مقداردهی اولیه پایه‌های GPIO.
- برقراری ارتباط سریال با نرخ 115200 بیت بر ثانیه.
- دریافت فرمان `GRANTED` برای روشن کردن LED سبز.
- دریافت فرمان `DENIED` برای روشن کردن LED قرمز.
- خاموش کردن هر دو LED در صورت دریافت فرمان نامعتبر.

در ادامه مشخص شد که اجرای مستقیم فایل `main.cpp` با دکمه Run در VS Code امکان‌پذیر نیست؛ زیرا این فایل کد منبع مخصوص میکروکنترلر است و ابتدا باید توسط کامپایلر مناسب برای ESP32 کامپایل شود.

همچنین تلاش برای اجرای یک دستور نمونه که شامل مسیر فرضی فایل اجرایی بود، به دلیل واقعی نبودن مسیر، با خطای شناسایی نشدن برنامه مواجه شد.

## ۴. تصمیم جدید برای ادامه پروژه

با توجه به مشکلات نصب و دسترسی به ابزارهای توسعه، استفاده از شبیه‌ساز آنلاین Wokwi به‌عنوان جایگزین موقت برای آزمایش کدهای ESP32 انتخاب شد.

مزایای این تصمیم:

- امکان شبیه‌سازی ESP32 بدون نیاز به اتصال فیزیکی برد.
- امکان آزمایش LEDهای سبز و قرمز.
- امکان شبیه‌سازی رله و مدار کنترل قفل.
- امکان استفاده از نمایشگر LCD مجازی.
- امکان بررسی رفتار سیستم پیش از اتصال قطعات واقعی.

همچنین مشخص شد که شبیه‌سازی حسگر اثر انگشت در Wokwi ضروری نیست؛ زیرا احراز هویت بیومتریک می‌تواند از طریق حسگر اثر انگشت گوشی هوشمند و فناوری WebAuthn انجام شود و نتیجه احراز هویت به کامپیوتر و سپس ESP32 ارسال شود.

در ادامه، مراحل زیر دنبال خواهند شد:
